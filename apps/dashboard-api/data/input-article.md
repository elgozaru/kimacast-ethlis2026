# Et si nous parvenions à décrypter les ondes cérébrales? (V187)

Source: arbredespossibles.com, "Scénarios du Futur - Les grandes avancées
technologiques", section "Maîtrise du cerveau". Reader-submitted scenario,
reference code V187.

L'étude approfondie du cerveau a permis de décrypter les ondes cérébrales
émises par les neurones. Une fois analysées par un ordinateur, ces ondes
peuvent être transcrites en mots ou en images. Un jour prochain, des
machines parviendront à lire dans nos pensées...
