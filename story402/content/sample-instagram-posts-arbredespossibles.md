| Comic-panel hook | `splitStory.ts` → 0G Compute inference call, prompted for comic-caption style |
| Free teaser | `splitStory.ts` heuristic split (first ~25% of scenario text) |

| Published caption | `instagram.ts` → Meta Graph API `media` + `media_publish` |
