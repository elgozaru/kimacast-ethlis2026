# Story402 x L'Arbre des Possibles — 20 X (Twitter) Post Concepts

> **Source:** same real content as the Instagram comic-format set —
> `arbredespossibles.com/FutursTechno3.html` (Génétique + Technologie
> Médicale sections), captured via the user-supplied PDF snapshot. Each
> post is an original retelling of a real, publicly posted speculative
> "Et si...?" scenario — summarized, never reproduced verbatim, tagged
> with the site's own reference code for traceability.
>
> **Why this differs from the Instagram set:** X rewards brevity and
> threads, not long captions and hashtag walls. Format per post:
> **Tweet** (≤280 chars, no URL — the link is appended separately, same
> as `x-agent/agent.js`'s `generateContent`) → optional **thread reply**
> (one extra tweet to build a mini-thread without spoiling the ending) →
> **image concept** (single hero image, not a multi-panel carousel) →
> **image-gen prompt** → **2–3 hashtags** (X convention, not 10–15) →
> short **CTA**.

## How this maps to `x-agent/`

| Post field | Produced by |
|---|---|
| Tweet text | `x-agent/agent.js` → `generateContent()` (Claude drafts the ≤280-char hook from the Research Agent's notes) |
| Thread reply | Not yet in the pipeline — would need a `generateThread()` variant returning an array of follow-up tweets |
| Image concept + image-gen prompt | Not yet in the pipeline — same gap noted for the Instagram comic-format set |
| Hashtags + CTA | Currently folded into the single tweet text in `index.js` (`${draft.text}\n\n${url}`); would need a small change to append 2–3 hashtags before the link |
| Published tweet | `x-agent/twitter.js` → `publishTweet()` |
| Engagement metrics | `x-agent/twitter.js` → `getTweetMetrics()`, written back to 0G Storage |
